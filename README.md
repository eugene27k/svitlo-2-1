# Світло 2.1 — розширення Chrome

Попереджає про відключення світла за графіком погодинних відключень Миколаївобленерго
для черги **2.1** (сайт <https://off.energy.mk.ua/>). Сповіщення приходять за 30 хвилин,
за 15 хвилин і в момент зміни зони (червона / жовта / зелена), а також коли обленерго
змінює графік або публікує графік на завтра. Сповіщення за 15 хвилин і в момент зміни
супроводжуються звуком: зелена зона — приємний акорд, жовта — нейтральні гудки,
червона — тривожний сигнал.

Розширення — звичайний код без ШІ і зовнішніх сервісів: воно раз на годину читає ті самі
три JSON-адреси, що й сторінка сайту, перевіряє відповіді (П1–П12) і тримає актуальні дані
у `chrome.storage.local`. Поки комп'ютер увімкнений і Chrome відкритий — графік актуальний.

## Встановлення

1. Відкрийте `chrome://extensions`.
2. Увімкніть **«Режим розробника»** (перемикач угорі праворуч).
3. Натисніть **«Завантажити розпаковане»** і виберіть цю папку (`svitlo-2-1`, де лежить `manifest.json`).
4. Значок «Світло 2.1» з'явиться на панелі розширень. Закріпіть його, щоб бачити мітку:
   кольор мітки — поточна зона, текст — скільки до наступної зміни (`30хв`, `2г`).
   Сіра мітка `?` — графіка на сьогодні немає; `!` — дані старші за 3 години.
   За 15 хвилин до зміни зони мітка моргає: приблизно раз на секунду перемикається
   між кольором поточної зони і кольором наступної, поки не настане зміна.

Після встановлення розширення одразу бере дані; далі — раз на годину, при запуску Chrome
і після пробудження комп'ютера. Якщо сайт недоступний — повтор через 5 хвилин, потім через
15, далі за годинним розкладом; все цей час воно працює на останніх успішних даних.

## Вікно розширення

Клік по значку відкриває вікно: поточна зона і наступна, візуальний розклад доби —
кольорові смуги на 24 години для сьогодні і завтра, де ширина кожної зони
(зелена-жовта-червона) відповідає її тривалості, з позначкою «зараз», поділками годин
і підсумками (наприклад, «червона — 5 год»); далі відрізки текстом, час оновлення,
звірка внутрішнього номера черги і результати перевірок.

Усі дії — рядок іконок у шапці справа (без тексту, мінімалізм); значення кожної —
у спливаючій підказці при наведенні:

- **Оновити зараз** (кругова стрілка) — отримати дані поза розкладом;
- **Скопіювати звіт для налагодження** (два прямокутники) — кладе в буфер обміну
  повний звіт у Markdown (версія, результати перевірок П1–П12, відрізки, заплановані
  сигнали, журнал, сирі тіла відповідей); на 2,5 с іконка стає зеленою галочкою.
  Саме його вставляйте в чат із Claude Code / Codex, якщо щось працює не так;
- **Надіслати тестове сповіщення** (дзвіночок) — перевірка, що сповіщення системи працюють;
- **Прослухати звуки зон** (динамік) — три звуки підряд (зелена, жовта, червона), як у справжніх сповіщеннях;
- **Відкрити сайт обленерго** (стрілка назовні);
- **Тема** (монітор/сонце/місяць) — перемикає вигляд вікна: **Системна → Світла → Темна**.

Іконки — інлайнові SVG зі `stroke="currentColor"`: колір успадковується від теми,
тож окремі версії для світлої/темної не потрібні. У режимі «Системна» вікно слідує
за темою Windows/macOS і змінюється разом з нею на льоту; явні режими фіксують
світлу або темну палітру, вибір запам'ятовується. Темна палітра — той самий макет
із м'якими відтінками зон і акцентів для темного фону (потрібен Chrome 123 чи новіший).

## Сповіщення

Windows: дозвольте сповіщення для Chrome у _Параметрах → Система → Сповіщення_.
macOS: _Системні параметри → Сповіщення → Google Chrome_. Режим «Не турбувати» ховає їх.
Клік по сповіщенню відкриває сайт обленерго.

Звук супроводжує сповіщення за 15 хвилин до зміни і в момент зміни зони (також після
пробудження комп'ютера, якщо зона змінилася): зелена — короткий мажорний акорд, жовта —
два нейтральні гудки, червона — тривожний двотональний сигнал. Попередження за 30 хвилин
проходить без звуку. Звуки синтезуються Web Audio API (без аудіофайлів) у прихованому
offscreen-документі, тож потрібен Chrome 109 чи новіший; стандартний системний звук
сповіщення зберігається.

## Розробка

```
manifest.json        — Manifest V3
src/background.js    — розклад, отримання даних, сигнали, мітка (service worker)
src/api.js           — запити до трьох адрес сайту (20 с, без кешу)
src/validate.js      — перевірки П1–П12
src/schedule.js      — київський час, стани, відрізки (правила 2.1–2.3)
src/plan.js          — моменти сповіщень і їх об'єднання
src/diff.js          — порівняння графіків
src/texts.js         — тексти сповіщень, мітки, вікна і звіту
src/sound.js         — специфікації звуків і вибір звуку для сповіщення
src/offscreen.html/js — прихований документ-програвач звуків (Web Audio API)
src/blink.js         — моргання мітки за 15 хв до зміни зони
src/theme.js         — цикл теми вікна (системна/світла/темна)
src/log.js           — журнал (500 записів)
popup/               — вікно розширення
tests/               — тести node --test, контрольний приклад у fixtures/
tools/gen-icons.js   — генератор іконок (node tools/gen-icons.js)
```

Тести: `node --test` із кореня проєкту (Node 18+, без сторонніх пакетів).
Логіка, яку можна перевірити без браузера, винесена в чисті функції без `chrome.*`;
поточний час завжди передається параметром. Вимоги — у `PRD.md`.
